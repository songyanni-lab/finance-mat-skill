# 执行与验收

## 制作判断

内部简记主类型、客户问题、核心回答、对应证据、有效表达、理解障碍及拟用形式。新建页以任务目标替代原页目的。工作单无需放进对客页面。

关键结论须对应具体图中位置、数值与计算、原理过程、算例或规则。保留来源、日期、单位及假设；详细链接和推导可放备注，会改变结论的条件应在页上可见。来源需可定位，不能只写机构名。

检查结论与证据是否回答同一问题。例如标题问“票息从哪里来”，只列到期结果仍未解释收益来源。

## 四项验收

1. 目的与结论：核心回答容易找到，与标题和主体一致，优化没有悄悄换题。
2. 证据与关系：论据充分、相关、可追溯，有效图示、案例和比较功能保留。
3. 理解与呈现：指出解决了哪个理解障碍；RM 可沿页面顺序讲清，图表有帮助，文字简洁可读。
4. 准确与完整：不无据扩写，不遗漏关键条件，数字/规则正确；检查字体、对齐、图例、单位、来源、统计时间、溢出与遮挡。

新建对照任务目标与来源，优化对照原稿。用一句话记录“保留了什么，改善了什么，仍缺什么”。加结论、加风险提示或加图表本身不足以证明优化成功。

## 文件与视觉

生成预览并逐页看图，优化时与原页并排比较。检查标注位置、图表日期及轴、中文字体、页脚和品牌。编辑一页不要连带改动其他页面。

核对文字、表格和图表的可编辑性及数据一致性。无法保留原模板或字体时如实说明。没有实际生成 PPT 或检查预览，不能报告完成。

## 状态

- 可交付：四项通过，完成要求的格式与必要视觉检查。
- 需返工：材料足够但解释或呈现未达标，继续修改。
- 待补充或核实：缺关键事实、条款、资料或验收能力，说明具体缺口，不称对客定稿。

交付以文件为主，重要纠错说明“原文—修正—依据”。内部审查意见与客户正文分开。
