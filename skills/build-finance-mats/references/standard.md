# 垫板制作规范 V2 修订版

版本日期：2026年10月29日

适用范围：金融业务垫板的新建与存量优化，供顾问及 Agent 使用。

版本说明：根据高票材料的有效做法及优化测试反馈修订。本文件作为后续制作依据，原 V2 文档保留供追溯。

## 一、总体说明

垫板用于帮助 RM 向客户解释市场、概念、产品、工具选择和政策。制作效果应达到：**结论清晰，论据有理有据且能够支持结论，呈现简洁清楚，并用必要的图表辅助理解。** 客户应容易找到本页的核心回答，RM 能沿着页面顺序讲清依据及其意义。

每页围绕一个核心问题组织内容。“结论”可以是市场判断、关键原理、工具之间的取舍或规则的具体影响，无需每页给出投资建议。主题标题可以保留，但页面显著位置应有明确的核心回答；回答的范围和确定程度须与证据相符。

存量优化先识别原页的沟通目的和有效表达，优先保留有价值的图示、案例、数据及比较关系，针对具体理解障碍修改。更换图形时，应保留其承担的证据与解释作用；原主题无法概括内容时才改题。新建页面先明确客户问题与证据，再选择表达形式。

以下条目是内容检查要求，不对应固定版式或独立区块。同一图示、表格或案例可以满足多项要求。按本页主要类型检核，必要时参考其他类型，不机械叠加全部要求。

### 内容与呈现边界

- **基于材料加工。** 可以归纳、删减、重组已有内容，或作有依据的计算与推导；不得擅自增加投资观点、产品特点、条款、预测或推荐排序。事实核查发现明显错误时，应纠正并在备注或交付说明中记录原文、修正内容及依据。
- **结论有对应依据。** 关键回答须能在图表、原理、算例或规则中找到支持。数据注明来源、期间、单位及必要口径；算例交代假设；政策注明官方依据与适用时点。区分事实、解释和推论，不把相关性写成因果，不把历史频次当作未来概率。
- **图表承担解释任务。** 趋势与数值关系可用数据图表，运作过程可用流程或资金流向图，工具差异可用共同维度对照，条件与期限可用分支或时间线。按需选择，不强制每页有图，也不以装饰图替代证据。文字说明关键关系与意义，避免逐项复述图表。
- **简洁但不丢失必要内容。** 减少重复、无关信息和装饰，保留支撑结论的证据及会改变结果的条件。不能仅靠删掉图表、比较维度或机制过程来减少字数，也不能用长篇文字填满页面。
- **延续指定视觉语言。** 存量优化沿用原模板、品牌元素及配色，字体使用微软雅黑，除非任务另有要求。图例、重点标注和阅读顺序清楚，避免缩小字号硬塞内容。交付 PPT 时，文字、表格、数据图表和必要的机制图尽量保持可编辑。

若原证据不足以支撑原结论，应保留可用证据，说明缺口，并收准结论或标明待核实。不得默默换成另一命题，也不得把内部审查意见当作对客页面的主体。

## 二、四类垫板的制作要求

### 1. 市场趋势与指标解读

**目标：** 让客户看懂数据中值得关注的变化、差异或关系，以及它的实际意义。

1. **根据数据提炼明确判断。** 围绕一个市场现象、趋势或指标关系，从相关数据中识别最值得关注的信息，用简短语句表达。避免只重复图表标题，或停留在“有波动”“存在差异”等泛泛描述；不先定结论再挑选数据。
2. **让客户在图中找到依据。** 保留支持判断的走势与比较关系，标出相关时间、区间、拐点、水平或差异，交代指标口径、比较对象及时间范围。多个指标共同说明一个关系时，应呈现并解释它们之间的联系。
3. **说明具体意义及边界。** 解释这些数据怎样帮助客户理解市场、比较产品条件或考虑配置。解读应针对本页的具体对象，不以通用风险提示替代。证据不足以支持投资建议时，给出明确的市场理解或比较参考即可。

**方法示例：美债收益率与障碍水平。** 在同一历史走势图上叠加不同障碍线，统计超过各水平的天数并说明观察口径，让客户直观看到不同障碍条件的历史触及差异。这为比较产品条件提供参照，不能单独决定产品是否适合客户，也不能直接推算未来触及概率。

### 2. 基础知识及产品机制

**目标：** 让客户理解一个概念、方法或机制，以及关键条件如何影响结果。

1. **聚焦要解释的关键关系。** 定义用于建立基本认识，主体还应讲清原理或运作过程。机制页按主题说明必要的参与方、资金或权利流向及收益、成本、风险的来源；概念和方法页说明关键变量及使用条件，不要求一页覆盖全部产品知识。
2. **用合适形式把关系具体化。** 可用流程、资金流向、对照、数字算例或熟悉场景，展示过程与结果之间的联系。图示应帮助客户看懂“如何发生、为什么产生这一结果”，不能只列不同结果而省略本页要解释的机制。
3. **保证示例严密且能支持回答。** 算例和测验交代必要条件、单位和计算口径，答案能由已给信息推出。类比说明关键对应关系及重要差异。条件不足的题目应补足已有依据或改为案例解读，不能答题后才加入决定性条件。

**方法示例：用贷款买房理解保费融资。** 两组资金流向图采用对应结构，把自有资金、贷款、资产收益和利息成本逐项对应，再解释收益率、贷款利率及杠杆如何影响结果。熟悉场景帮助理解，产品自身的重要差异仍须说明。

### 3. 工具比较与选择

**目标：** 让客户看懂工具之间的实质差异，并根据自身需求理解主要取舍。

1. **明确需求与比较范围。** 说明要解决什么需求，再确定相关工具、产品或机构。对象与标题一致；机制明显不同的类别应拆分或标注，避免混作同类。
2. **保留影响选择的共同维度。** 按需求比较成本、门槛、收益来源、风险、期限、流动性或使用限制等关键因素，不机械列全。同一维度采用可比口径，不能直接比较时说明原因。客户应能方便地横向查找差异。
3. **提供有依据的选择参考。** 说明不同需求应重点比较哪些因素；原材料足够时，再说明什么条件下更适合哪类工具、需要接受什么限制。选择参考须来自前面的差异，不能以简短推荐替代具体比较，也不强行排名或选出唯一优胜者。

**方法示例：黄金投资工具比较。** 用共同维度呈现成本、门槛、金价关联度、风险及代表产品，帮助客户按关注点查找与比较。需要时补充需求对应关系，同时保留支持选择的差异；杠杆、反向等机制不同的工具须单独识别。

### 4. 政策规则解读

**目标：** 让客户知道规则是否适用、会产生什么影响，以及需要关注或办理什么。

1. **说清适用条件。** 说明适用对象、触发情形、关键条件及相关时间。涉及新旧政策时，明确哪些内容发生变化、影响谁及必要的过渡安排。
2. **把规则落到具体情形。** 对应解释客户的权利、义务、税费、成本或办理安排如何受到影响。可用情形对照、案例、条件分支或时间线，使客户容易找到与自己相关的处理方式，避免只摘录条文。
3. **按页面目的说明后续事项并对应依据。** 规则解释页重点说明判断条件、处理差异及待确认问题；涉及办理时，再列步骤、资料和期限，并写清期限的起算点。关键解释须有对应官方依据，区分明确规定、附条件适用和尚未明确事项。

**方法示例：境外保险税务热点。** 将收益类型、适用税务情形和法律依据对应呈现，用有完整条件的融资保单算例解释处理差异，并标出尚未明确之处。规则和案例须按适用时点核查，不能把个案处理推广为普遍结论。

以上示例用于说明有效方法，不构成固定版式，也不要求其他页面照搬其内容。

## 三、制作与前后对照验收

制作前，先用简短文字明确：本页回答什么问题、原有内容中什么有效、具体哪里影响理解、准备怎样改善。该判断供内部制作使用，无需放入对客垫板。

完成后，对照原页检查以下四项；新建页面则对照任务目标与来源材料：

1. **目的与结论：** 是否仍回答本页的核心问题？核心回答是否容易找到，且与标题和主体内容对应？
2. **证据与关系：** 关键结论能否找到充分、相关且可追溯的依据？原有有效证据、图示关系、案例及比较维度是否保留；替换后是否仍发挥同样的解释作用？
3. **理解与呈现：** 具体解决了什么理解障碍？客户是否更容易看懂关系、运作过程、工具差异或适用条件？RM 能否沿页面顺序讲清？图表是否必要且有帮助，文字是否简洁可读？
4. **准确性与完整性：** 是否引入无依据的新观点，遗漏影响结论的条件，或产生数字、口径和规则错误？同时检查字体、对齐、图例、单位、来源、统计时间、溢出与遮挡。

验收可用一句话记录：**“保留了什么，解决了什么理解障碍，是否还有未解决的问题。”** 仅增加结论文字、补充风险提示或统一排版，不能单独证明优化成功。

四项通过后交付；已有材料足够但解释或呈现未达标的，继续修改；关键证据或条款尚缺的，明确标为待补充或核实，不能称为可直接对客使用的定稿。
