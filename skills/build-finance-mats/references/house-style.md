# 机构配置接口

开发者可调整下列默认值。每次任务读取，当前用户明确要求优先；配置不能放宽事实准确要求。

| 项目 | 默认值 |
| --- | --- |
| 语言 | 简体中文 |
| 字体 | 微软雅黑；不可用时告知并选可用中文字体 |
| 新建模板 | 任务提供模板优先；没有则简洁排版，不虚构机构品牌 |
| 存量模板 | 保留原母版、品牌、配色及有效图示 |
| 格式 | 可编辑 PPTX；能力不足按 SKILL.md 降级 |
| 页数 | 一个核心问题默认一页，指定页数优先，不额外加封面 |
| 数据时点 | 用户指定优先；否则注明实际来源截至日期 |
| 地区与法规 | 根据任务或来源确认，不从语言、IP或币种推定税收居民身份 |

模板及品牌素材由开发者另行提供，可放 assets/ 并在此写相对路径。未提供前不得声称随包附带。不把客户个人信息或未授权材料加入通用发布包。
