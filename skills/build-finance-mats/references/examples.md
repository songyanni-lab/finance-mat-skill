# 表达方法与失败模式

以下用于迁移方法，不提供现行规则、实时数据或实际产品条款。

| 内容关系 | 有效方法 | 避免的做法 |
| --- | --- | --- |
| 历史走势与产品障碍 | 同图叠加障碍线，按同口径统计历史超越天数 | 当作未来概率，或只说“有波动” |
| 熟悉场景解释陌生机制 | 房贷与保费融资的资金流向逐项对应，解释收益、成本、杠杆及差异 | 只列最终结果，删掉资金流向与收益来源 |
| 同一需求下工具比较 | 共同维度横向比较，再提示需求对应的关注因素 | 一句推荐替代具体差异，或强行排名 |
| 不同情形适用规则 | 收益类型、条件、规则、案例对应；有办理再补期限 | 每页都做成办理清单，或只摘录法规 |
| 客流与保费共同变化 | 保留折线与柱形叠加，清楚标注双轴单位和时间 | 删一条序列而换题，或直接认定因果 |
| 净值与客户收益 | 保留已知值，解释持有和卖出条件 | 虚构中间路径、卖出价；缺条件却断言谁先翻倍 |

原页有口径错误，不代表原图示无效。高票意味着表达值得借鉴，不保证事实全部正确；发现问题不代表整页推倒重做。

只有端点数据时可以端点对照，但须检查这幅图是否真正解释本页核心问题。若问题在持有过程，端点柱状图不能替代过程解释。

用户认可某次改法，不自动变成统一版式。待审阅的页面不能标为已认可范例。
